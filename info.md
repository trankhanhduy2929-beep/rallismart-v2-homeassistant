# RalliSmart V2 cho Home Assistant

Tích hợp điều khiển nhà Rang Dong **RalliSmart V2** trên Home Assistant:
đèn, công tắc (gom panel nhiều nút), rèm/cửa cuốn, cảm biến, camera, scene.

- Cài qua **HACS** (custom repository) hoặc copy thủ công.
- Cần **License Key**: đăng ký/mua tại website bản quyền.
- Mỗi License Key dùng cho **một** cài đặt Home Assistant.

Xem hướng dẫn đầy đủ trong `README.md`.
